# Multiplayer Tetris Game

This project is a web-based multiplayer Tetris game built with Node.js, Express, and WebSockets.

## Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (which includes npm, the Node Package Manager)

## Getting Started

1.  **Clone the Repository or Download Source Code:**
    ```bash
    # If using git
    git clone <repository_url>
    cd <repository_directory>
    ```
    Alternatively, download and extract the source code ZIP file. Replace `<repository_url>` and `<repository_directory>` with the actual URL and directory name if applicable.

2.  **Install Dependencies:**
    Navigate to the project's root directory in your terminal (the directory containing `package.json` and `server.js`) and run the following command to install the necessary Node.js packages:
    ```bash
    npm install
    ```

3.  **Start the Server:**
    Once the dependencies are installed, you can start the server with:
    ```bash
    npm start
    ```
    This will execute `node server.js`. You should see a confirmation message in your terminal, typically:
    `HTTP server listening on port 3000` (or the configured port).

4.  **Access the Game:**
    Open your web browser and navigate to:
    ```
    http://localhost:3000
    ```
    This will load the main menu of the game.

## Project Structure

- `server.js`: The main Node.js server file, handling HTTP requests and WebSocket connections.
- `package.json`: Defines project metadata, dependencies, and scripts.
- `package-lock.json`: Records exact versions of dependencies.
- `.gitignore`: Specifies intentionally untracked files that Git should ignore.
- `public/`: Contains all client-side static assets:
    - `main.html`: The main menu page.
    - `index.html`: The Tetris game page.
    - `style.css`: CSS styles for the game.
    - `main_menu.js`: Client-side JavaScript for the main menu and matchmaking initiation.
    - `script.js`: Client-side JavaScript for the Tetris game logic.
- `node_modules/`: Directory where npm installs project dependencies (generated by `npm install`, should not be committed).
